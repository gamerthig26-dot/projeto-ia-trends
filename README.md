# IA Trends

Plataforma de pesquisa de tendencias e produtos em alta, com geracao de roteiros para videos curtos.

## Fontes de dados
- Google Trends - Interesses de busca (24h / 7 dias)
- Mercado Livre - Produtos via API autenticada (OAuth + PKCE)
- Amazon, Shopee, AliExpress, TikTok Shop - integracao pendente

## Funcionalidades
- Pesquisa de tendencias e produtos
- Cruzamento de oportunidades (tendencia x produto)
- Geracao de roteiros de 20-30s para videos curtos
- Prompts detalhados para ferramentas de video externas
